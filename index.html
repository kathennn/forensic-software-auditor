Start in seconds

Generate a read-only inventory using Node.js 18 or newer:

npx forensic-software-auditor
npx forensic-software-auditor ./my-project --output audit-inventory.md

The CLI does not execute project code. Inventory is a starting point, not a completed security audit.

Built around honest evidence

Confirmed, probable and unverified findings stay distinct. Commands, test results, scope limitations and unreviewed files are recorded. No scan or score is presented as a security certification.
